# GC Minimal Zine Poster v0.1（映栈受限适配）

只作为图片 Agent 的创作方法，不执行脚本、联网、文件或外部写入。

## 编译顺序

1. 画布：竖版 3:5、全幅旧纸、无边框、无样机。
2. 注意力几何：70%–90% 留白；单一视觉簇占 8%–25%，不贴边。
3. 图像锚点：把主题压缩为一个物件、照片裁片、剪影、纸片或概念关系。
4. 纸面处理：复印柔化、网点、孔版印刷颗粒、套印偏移、墨渗与扫描纤维。
5. 排版：短句、小号衬线/打字机/等宽字；微文字只作层级，不堆长文。
6. 色彩：纸色与灰黑为底，只保留一个缩略图仍可见的高饱和色锚点。
7. 情绪：安静、诗性、怀旧、日记式、档案式；平视扫描、漫射光、无三维深度。

## 变化配方

每次从布局、锚点、字体、质感、色锚和情绪各选一项，避免只改位置。输出应能说明采用了哪组配方。

## 禁止项

避免通栏商业标题、产品广告、Logo/CTA、全幅场景、光亮样机、电影灯光、3D、霓虹、可爱卡通、时尚大片、密集手账、过多颜色和长段可读文字。

## 质量门禁

检查留白比例、视觉簇比例、单一隐喻、纸面复制质感、排版层级和唯一高饱和锚点；用户未要求单色时，不得把色锚弱化成不可见的小点。
