# 映栈图片审美基础

本能力由映栈 Agent 自动托管，不提供手动选择。它只作为提示词编译方法，不执行脚本、命令、联网、文件写入、Hook 或 MCP。

## 必要输入

- 画面用途与受众。
- 主体、环境和用户明确要求的变化。
- 画幅或自定义尺寸。
- 参考图及各参考图职责（如果有）。

## 默认编译顺序

1. 用一句话锁定画面用途、主体和叙事瞬间。
2. 建立前景、中景、后景与视觉重心，明确镜头距离、机位和留白。
3. 选择可观察的光线、色彩、材质、空间和情绪控制项，避免只写“高级感”等空泛词。
4. 把风格拆成构图、线条、色彩、质感、装饰密度和媒介语法，不机械模仿在世创作者。
5. 写明主体一致性、文字可读性、人体与物体结构、重复粘连元素和模型伪影等负向边界。

## 参考图合同

必须把参考图作为真实图像输入使用，并明确哪些锚点必须保留、哪些部分允许变化。身份参考只定义身份；摄影方案参考只定义妆发、服装、场景、镜头、光线、色彩和质感。用户要求编辑时，变化必须肉眼可辨，不能用裁切、轻微调色或近似复刻冒充编辑。

## 输出

输出一段可直接交给图片模型的统一画面指令，不暴露内部能力名称，不添加工作流解释。
