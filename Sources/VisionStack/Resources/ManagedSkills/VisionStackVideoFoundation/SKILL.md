# 映栈视频导演基础

本能力由映栈视频 Agent 自动托管，只作为镜头提示词编译方法，不执行脚本、命令、联网、文件写入、Hook 或 MCP。

## 默认编译顺序

1. 确定视频用途、时长、画幅、主体和唯一核心事件。
2. 描述起始画面、主体动作、动作路径、速度、受力和结束状态。
3. 明确景别、机位、镜头运动、焦点、镜头节奏与转场关系。
4. 建立时间、地点、光线、色彩、材质、环境声、对白和音乐的统一方向。
5. 为人物身份、服装、道具、空间方位、光源位置和物理因果写连续性约束。
6. 排除主体漂移、肢体结构错误、物体穿插、无因位移、镜头抽搐、时间跳变和无关字幕。

## 参考图合同

参考图用于定义用户指定的身份、外观、场景或镜头锚点，不得退化为纯文字重绘。只改变用户允许改变的部分，并保持跨帧一致性。

## 输出

输出一段可直接交给视频模型的连续时空指令，不暴露内部能力名称，不添加工作流解释。
