# 写真复拍方向（映栈受限适配）

只作为图片 Agent 的创作方法，不执行上游脚本、命令、联网或外部写入。

## 参考职责

- 身份参考只回答“她是谁”：保留可识别的面部与身份锚点，不把原发型、服装、表情、光线和背景误当作必须复制。
- 摄影方案参考只回答“这一组如何拍”：提供妆发、服装、场景、机位、镜头、光线、色彩和质感，不覆盖身份。

## 画面推理

- 相机移动时在世界空间重建光线拓扑：太阳、窗户、遮挡物与反射面的物理位置不随相机一起移动。
- 表情必须由具体场景事件触发，眼神、呼吸、嘴角、手势和身体重心响应同一事件。
- 背景建立四级信息层：主体清晰区、主导大形、次级细节、低细节静区。
- 原参考若依赖欠曝、遮影、轻微失焦、风感或抓拍感，不要自动抛光成商业棚拍。

## 迭代约束

每轮从原身份参考、原摄影方案参考和重新编译的完整提示词开始。上一轮生成图只用于诊断失败，不得自动变成下一轮视觉输入；只有用户明确要求编辑上一张时例外。
