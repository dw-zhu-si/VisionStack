# 映栈 VisionStack 0.9.0-beta.1（Windows）

这是 Windows 客户端的受限核心 Beta 候选，不是 macOS 版本的完整功能对齐版。

首个切片包含：

- ModelHub 与任意厂商直连配置；
- 本地端点安全校验；
- 普通配置与 API 密钥分离；
- Windows DPAPI 当前用户范围密钥保护；
- 厂商配置新增、切换与删除，内置 ModelHub 入口保护；
- `win-x64` 与 `win-arm64` 独立安装包通道。

对话、生图、视频、参考图、Agent/Skills、项目、任务与费用功能仍在后续阶段开发。公开发布前必须完成受信任 Authenticode 签名、真实 Windows 安装/升级/卸载、Defender 与 SmartScreen 验收。
