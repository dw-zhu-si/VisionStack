# 映栈 VisionStack

映栈是面向 Apple Silicon Mac 的原生 AI 图片与视频创作工作台，用一个项目组织对话研究、参考图、图片、视频、分镜、版本评审、任务与费用记录。

本仓库是映栈的官方公开下载页，只发布经过 Developer ID 签名、Apple 公证、Staple 和 Gatekeeper 验证的安装制品，不包含应用源码。

## 下载

请从 [Releases](https://github.com/dw-zhu-si/VisionStack/releases) 下载最新的 DMG，并使用同一 Release 中的 `.sha256` 文件核对完整性。

## 运行要求

- Apple Silicon Mac
- macOS 14 或更高版本
- 需要 AI 模型功能时，请另行安装并运行 [ModelHub](https://apps.apple.com/cn/app/id6797847364)

映栈本身免费且不包含应用内购买。第三方模型服务商可能对模型调用另行收费；发送前由应用明确提示并要求同意。
